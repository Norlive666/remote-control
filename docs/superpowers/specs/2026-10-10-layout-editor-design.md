# 控件位置编辑设计（已确认）

目标：保持雾白方格样式，让用户在手机上调整操作控件位置并保存，解决固定位置不顺手的问题。

推荐采用独立控件自由拖动：两个摇杆、两个滑块、使能控件和三个功能按钮分别移动。另一种较小的方案只移动摇杆和滑块；仅左右交换虽然改动更少，但无法满足任意位置调整。

从设置进入“编辑布局”。进入时关闭使能、摇杆归中，编辑期间控件只用于拖动，不执行遥控或按钮动作。蓝牙若已连接，继续发送禁用帧；保存或取消都不自动重新使能。

编辑工具栏固定可见，提供“保存”“取消”“恢复默认”。原布局作为默认；位置按可用屏幕区域的比例保存到本机设置，打开 App 或改变屏幕尺寸后重新计算并限制在屏幕内。取消丢弃本次改动，恢复默认先作用于编辑草稿，保存后才持久化。此次仅编辑位置，不加入缩放或新增组件。

标题、连接状态、底部状态和设置入口固定，确保始终能进入编辑并恢复布局。隐藏的功能键仍保留自己的位置，重新显示时沿用。

实现边界：仅修改 Android 布局和本机设置，不改变蓝牙传输、20 字节协议或 STM32 接收端。发布新版 APK，用本机已有密钥签名，可覆盖升级 v1.0.0。

验证：位置拖动/边界限制、保存/取消/恢复默认、重启后的布局恢复、不同屏幕尺寸中的位置范围；原双摇杆多点触摸和急停测试保持通过。模拟器检查编辑模式中的控件不会产生遥控量，保存后控件仍可正常操作。
