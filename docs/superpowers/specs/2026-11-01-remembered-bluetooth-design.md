# 记忆设备与快捷连接

用户已批准：连接成功后记住设备名称和地址，跨App重启保留；主面板连接键短按连接上次设备，已连接时断开，连接/等待中短按取消；长按打开现有设备列表；首次无记录时短按也打开列表。设备暂时不在线时持续重试，间隔逐步增加至5秒；蓝牙关闭或权限不足时停止并提示。真正重新连上仍需手动使能。

复用Bt630Session的单会话、10秒连接超时、串行写及取消机制，暂时失败不再以五次为上限；UUID不匹配等永久错误仍终止。关闭旧GATT后再重试，等待间隔1/2/4/5/5秒；稳定连接10秒后的下一次掉线重置退避。只在Ready（服务与订阅均成功）时更新本机SharedPreferences里的设备名称/地址，失败尝试不能覆盖旧记录；断开不清除记忆。

主键显示记忆/当前设备名称及简短操作提示，以combinedClickable区分短长按并保留无障碍动作。长按只打开列表，不执行短按连接或断开；列表连接前取消旧会话，选择不同设备允许切换。列表关闭本身不取消主面板发起的等待或连接；保留显式取消/断开按钮。无记忆短按沿用列表扫描及权限流程，记忆直连申请所需连接权限，不强制扫描或系统配对。权限请求回调必须执行原先意图，过期请求不得意外连接。

保持后台选项默认关闭；默认切后台仍停止连接/等待，开启且服务确实接管后保留原有后台行为。主动取消、蓝牙关闭、永久错误均释放会话/服务；真实掉线使能与控制值清零，重连不恢复使能。进程重启只恢复设备记录，不自动连接或恢复使能。设备地址改变时需长按重选。

仅修改Android App与相关测试/文档，不改STM32驱动、协议、用户本机其他工程、签名配置。发布App1.9.0/code15，继续本机原密钥签名，不上传密钥。

验证：先用现有实现证实持续重试/记忆/手势回归失败；新增覆盖第六次及后续重试、5秒上限、取消、永久错误、成功后记忆与失败不覆盖、重启恢复、首次短按列表、记忆短按直连/取消/断开、长按不误触、后台与权限回调。全单元/API35界面检查与构建通过后本机签名，发布GitHub并重新下载校验；手机BT630实物重试仍需复测。

Android接口依据：[GATT连接](https://developer.android.com/develop/connectivity/bluetooth/ble/connect-gatt-server)、[长按交互](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/tap-and-press)。
