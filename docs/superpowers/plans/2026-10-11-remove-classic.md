# 删除经典蓝牙

用户已确认 BLE 串口可连接，要求删除原 HC-05 经典蓝牙部分。

- 删除 HC05 模式、RFCOMM 实现、已配对设备入口；保留 BLE_UART 与 BT630 的连接实现和发送周期。
- 默认 BLE_UART；旧 HC05 或未知设置回落到 BLE_UART，其他用户设置不变。
- 更新模式选择、说明及相关界面测试。协议与 STM32 文件保持不变。
- 验证：旧 HC05/空设置加载为 BLE_UART；界面不再有经典模式；BLE 与 BT630 可切换并持久保存；执行 Android 单元、界面和构建检查。
- 本机使用原签名密钥签名 v1.3.2 并发布 APK；不上传签名凭据。实物通信由用户继续验证。
