# Gamepad Implementation Plan

**Goal:** 接入原生安卓双摇杆及六个可自定义滑块设值按键。
**Architecture:** GamepadConfig保存纯映射与去重状态，GamepadInput接收Android事件，RemoteViewModel沿用现有ControlSession与发送循环，GamepadSettings编辑持久化映射。
**Tech Stack:** Kotlin / Android InputManager / Compose / JUnit / existing BLE.

- [x] 增加设置入口的失败UI用例，在现有版本验证功能缺失。
- [x] GamepadConfig.kt及JUnit：枚举六键、映射目标和值、档位协调、扳机60/40阈值与双来源去重。
- [x] GamepadInput.kt与MainActivity：onStart注册设备监听、onStop注销；dispatchKeyEvent与dispatchGenericMotionEvent识别原生手柄；复用axes()。
- [x] RemoteViewModel：加载/保存每键映射、默认恢复、按键设值、按键/设备状态、失焦与拔出清零；修改滑块档位协调映射。
- [x] GamepadSettings.kt：按钮打开独立滚动对话框，每键选择滑块及目标数值，显示手柄连接名与最近输入；保留现有设置顺序。
- [x] 测试设置持久化、事件路由、松开保持、重复/阈值、后台和拔出安全、既有Android/STM32回归；更新README、版本1.5.0/10。
- [x] 审查、CI、下载unsigned APK，本机签名并校验证书，发布到既有GitHub仓库。
